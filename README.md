## 👨‍💻 Sobre mim

Desenvolvo produtos que unem hardware e software, do firmware no ESP32 que controla o equipamento ao painel web e ao SaaS que o cliente usa no dia a dia. Na RALM, minha própria empresa, cuido do produto de ponta a ponta: placa, firmware, back-end, front-end e deploy. Sou bacharel em Ciência da Computação (CEUB) e estou cursando pós-graduação em Inteligência Artificial (UniCEUB), com base sólida em teoria dos grafos, sistemas distribuídos e compiladores.

- **Embarcados:** firmware ESP32 e Arduino em C++, com sensores (PZEM-004T, DHT22, nível de água), RTC DS3231, EEPROM, data logger em SD, RFID RC522, fitas WS2812B e servidor web com Wi-Fi AP no próprio dispositivo.
- **Full Stack:** Next.js 16 (App Router), React 19, TypeScript e Tailwind CSS 4 no front; Node.js/Express, Python (Flask, Django), Java 21 + Spring Boot, C# .NET MVC e Go no back.
- **Dados e autenticação:** PostgreSQL, Prisma, Supabase, Firebase, SQLite e Flyway; JWT + BCrypt, NextAuth, 2FA com TOTP e QR Code, validação com Zod.
- **Deploy:** Docker e Docker Compose, Vercel, VPS com Caddy/Nginx e HTTPS, GitHub Actions e Raspberry Pi.
- **IA e automação:** motores de decisão por regras, determinísticos e auditáveis; LLM local com Ollama (Llama 3); scraping com BeautifulSoup, Selenium, Google Sheets API e visão computacional com OpenCV/RTSP.
